## 三种摆法

- **悬浮窗口**：在电脑版 Chrome 和 Edge（116 及以上）或 Firefox（151 及以上）中点按页眉的“悬浮窗口”，一个小计时器会浮在所有窗口之上，即使幻灯片全屏也依然可见；Safari 和安卓不支持。原标签页被隐藏时，悬浮窗口能否继续保持屏幕常亮，我们还没有真机记录，请提前演练确认。其他浏览器不支持时，会改为打开一个小窗口。
- **第二个窗口**：把 AwakeTab 拖成小窗口放在屏幕一角，不要让幻灯片完全盖住它。
- **演讲者屏幕**：笔记本接投影时，让笔记本屏幕（演讲者视图）一侧保持显示 AwakeTab 标签页。

需要在其他窗口背后仍保持常亮时，可以使用适用于 Chrome 和 Edge 的 AwakeTab 扩展程序。

## 浏览器版本

2026年9月9日的支持矩阵中，原生唤醒锁的起始版本为 Chrome 84、Edge 84、Firefox 126、Safari 16.4、Samsung Internet 14；iOS 主屏幕 App 需要 18.4。旧版 Firefox 点按后会改用视频备用方案，耗电更多。

## 各系统的显示器超时在哪里改

- Windows：设置 → 系统 → 电源和电池。24H2 起“节电模式”改名为“Energy saver”，它可能调暗屏幕，但不会拒绝唤醒锁。
- macOS：系统设置 → 锁定屏幕 / 节能。屏幕被保持常亮期间，Mac 也不会进入空闲休眠。
- 如果会议室电脑由公司统一管理，锁屏策略可能被强制设定，这也不在屏幕唤醒锁的作用范围之内。

## 讲完之后

演讲结束后记得点按“停止”，或者直接关闭标签页，让电脑恢复原来的熄屏设置。时长到了而你还在答疑时，可以在提示里加时，不必重新开始。

## 为什么我们坚持只说真话

很多“防熄屏”网页靠循环播放一段视频，然后希望屏幕别灭。AwakeTab 以浏览器的 Screen Wake Lock API 为准：浏览器真正给出锁之后，才开始计时并显示常亮状态。台上最危险的不是锁被收回，而是标签写着“常亮”、实际早已失效——AwakeTab 不会让这种情况发生。

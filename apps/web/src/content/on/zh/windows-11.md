## 结论

在 Windows 11 上，Chrome 84 及以上版本和 Edge 84 及以上版本都能为可见的标签页提供原生屏幕唤醒锁。打开 AwakeTab，本页预设 1 小时，点按开始，状态标签显示“屏幕保持常亮”后，屏幕就不会按电源设置里的时间熄灭。同样的步骤在 Windows 10 上也适用。限制有三条：标签页被隐藏就会失效；合上笔记本盖子会睡眠；采用新式待机（Modern Standby）的电脑属于固件层面的另一回事，行为可能与预期不同。

## 不想改系统设置时

Windows 11 的熄屏时间在“设置 → 系统 → 电源和电池 → 屏幕和睡眠”里修改。改成“从不”当然可以，但很多人只是偶尔需要：看一场直播、盯一会儿监控面板、开一次长会。这时打开 AwakeTab 更省事，用完关掉标签页，系统设置保持原样。

## Chrome 和 Edge 上的注意事项

- 标签页必须可见。最小化、被全屏应用盖住或切到其他标签页，都会让状态变成“已暂停 — 标签页已隐藏”。
- Chrome、Edge（116+）和 Firefox（151+）支持“悬浮窗口”：一个小计时器浮在所有窗口之上，适合一边工作一边保持常亮。
- 需要在其他窗口后面也保持常亮，可以使用适用于 Chrome 和 Edge 的 AwakeTab 扩展程序。
- Windows 11 24H2 把“节电模式”改名为“Energy saver”。它和 Edge 的效率模式都不会让浏览器拒绝唤醒锁，但可能调暗屏幕。
- Firefox 126 及以上版本在 Windows 上同样支持原生唤醒锁，旧版 Firefox 需要点按后改用视频备用方案。

## 新式待机与合盖

不少轻薄本使用新式待机（Modern Standby），它在屏幕关闭后的行为由固件和驱动决定，与浏览器无关。无论是否新式待机，合上盖子都会让电脑进入睡眠，任何网页都阻止不了。

## 屏幕还是熄了？逐项检查

1. **状态标签**：显示“屏幕保持常亮”才代表浏览器真正持有锁；显示“已暂停 — 标签页已隐藏”说明窗口被最小化或遮住了。
2. **“已被阻止 — 这样解决”**：这不是省电功能造成的，常见原因是 Firefox 在未充电且电量不高于 5% 时拒绝了请求，提示里会写明原因和解决办法。
3. **地址**：必须是 HTTPS。从其他网站嵌入的 AwakeTab 可能没有获得唤醒锁权限，直接打开 awaketab.com 即可。
4. **公司策略**：企业统一下发的锁屏策略、银行网站的自动登出、监考软件，都不在屏幕唤醒锁的作用范围之内。
5. **显示器本身**：外接显示器因信号丢失自动进入休眠，也不是网页能控制的。

## 状态为什么值得信任

AwakeTab 只有在浏览器确认持有锁之后，才会显示“屏幕保持常亮”并开始计时；锁被收回或请求被拒绝时，状态标签会如实显示。计时以系统时间为准，电脑挂起后再恢复，剩余时间也不会出错。支持版本以 2026年9月9日的支持矩阵为准。

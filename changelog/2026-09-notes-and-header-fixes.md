---
title: N opens your notes again, and the tool header fits a 320 px phone
date: 2026-09-28
type: fixed
---

Pressing N (or the Notes button) opens the notes drawer again; the editor failed to start in the built site. Whatever you type straight after N now lands in the note in the order you typed it, instead of triggering other shortcuts, and Undo after Clear brings back the text you just typed. On 320 px phones the tool header no longer scrolls sideways now that it has a Sounds button, and on narrow screens the AwakeTab wordmark steps aside instead of running under the header buttons.

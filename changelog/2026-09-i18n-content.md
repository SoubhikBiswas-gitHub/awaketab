The ten most-read guides are now available in Spanish, Brazilian Portuguese, German, French, Japanese, Simplified Chinese and Hindi: cooking, downloads, presentations, iPhone Safari, Android Chrome, Windows 11, macOS, the greyed-out iPhone Auto-Lock fix, AwakeTab vs Caffeine and the browser support matrix. Each one is written for how people search in that language, embeds the tool with the same preset, and keeps every honest limit. They're marked "native review pending" and stay out of search results until a native speaker has checked them.

The language menu at the bottom of a guide now opens the same guide in the other language when there is one. Link previews for these pages show their title in the page's own script, including Japanese, Chinese and Hindi.

Long translated link labels and code snippets no longer run off the screen on narrow phones.

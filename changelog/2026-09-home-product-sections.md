Below the tool, the home page now starts with six common uses (cooking, reading, presentations, dashboards, video calls and downloads), each with a Start link that opens the tool at the right length, then the extension, the levels and a closing band that takes you back to the tool. It uses the full page width on large screens instead of a narrow column. How AwakeTab works, its limits and the questions people ask are in the docs, one link away.

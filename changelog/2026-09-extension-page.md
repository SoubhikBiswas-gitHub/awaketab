---
title: A clearer page for the Chrome extension
date: 2026-09-28
type: changed
---

The extension page now says what the extension does in one line, with the install button right below it. It shows what happens when you switch tabs with the web app and with the extension, walks you through setup in three steps (install, pin it, press Alt+Shift+A), explains each permission in plain words and answers the common questions. A second install button waits at the end of the page. In Firefox and Safari, where the extension cannot run, the page offers the web app instead.

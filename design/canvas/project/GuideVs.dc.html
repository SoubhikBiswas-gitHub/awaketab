AwakeTab vs nosleep.page

{{verifiedLabel}} By Soubhik Biswas

Both are browser tabs that use the Screen Wake Lock API, and both stop when the tab is hidden. Pick nosleep.page if you want one quick timer with nothing to set. Pick AwakeTab if you want a status pill that only says "Screen awake" once the browser agrees, an end time on the clock, or a session that survives a reload.

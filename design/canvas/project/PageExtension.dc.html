AwakeTab for Chrome

The web app can hold a wake lock only while its tab is visible. The extension asks Chrome itself to keep the display awake, or just the computer, so it keeps working when the tab is hidden or the window is minimised.

Add to Chrome Get it for Edge
Free. Works in Chrome and Edge (version 116 or later). Store links go live once the listing is approved.

What the extension adds

Same honest status as the web app. The difference is who holds the lock: the tab, or Chrome itself.

Privacy

Anonymous usage statistics are off by default. The extension never sends URLs, tab titles or site names, and it shows no ads.

Privacy policy

Using Firefox or Safari?

Firefox and Safari don’t give extensions a power API, so there is no AwakeTab extension for them. The web app keeps the screen awake while its tab is visible.

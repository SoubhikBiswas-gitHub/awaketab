About AwakeTab

AwakeTab is an independent project built and maintained by Soubhik Biswas. Its purpose is narrow: request a browser wake lock, show the result honestly, and make the common timer and until-time workflows fast without requiring an account.

How AwakeTab is checked

The lock layer is tested as a seven-state transition machine. Browser journeys inject a controllable Wake Lock implementation and verify acquisition, denial, release on hidden tabs, reacquisition, fallback behaviour and multi-tab warnings. Device claims are kept in the support matrix and are refreshed separately from application code.

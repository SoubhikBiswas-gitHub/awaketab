How it works, limits and support

What AwakeTab does

AwakeTab uses the browser's Screen Wake Lock API while this tab is visible, and its status only says the screen is awake after the browser confirms the lock.

Pick a duration, 15 min to 4 h, Custom… up to seven days, or Until… a clock time, and the display stops dimming and sleeping (a work idle-lock policy can still lock it). The pill reads Screen awake only while the browser is actually holding the lock. Hide this tab and the browser takes the lock back, so the pill switches to Paused — tab hidden and the timer stops until you come back.

No account, no download, no extension: the whole tool is this page. Settings, the current session and your stats stay in this browser, and nothing is sent unless you leave the optional usage beacon on. It works offline after the first visit, and Install AwakeTab in the header puts it on a home screen or dock.

How it works

  1. 1 You pick a duration. A preset, a custom length or a clock time starts a session. Each choice is one keypress: 1–6 presets 0 no end time U clock time Space start or stop
  2. 2 The browser is asked for a screen wake lock. The same Screen Wake Lock API a video player uses. The browser can accept, refuse, or take the lock back later; all three answers show as they happen.
  3. 3 The timer follows the lock, not the clock. The countdown runs only while the lock is held, on system time, so a suspended laptop comes back with an honest number. When time is up you get a chime and the choice to extend or stop.

A lock has exactly seven states, and the pill names the one you are in.

Honest limits

  • A hidden tab cannot hold a wake lock. Switching apps, minimising or changing tabs pauses the session. That is a platform rule. For a display awake behind other windows, use the AwakeTab extension for Chrome and Edge.
  • Closing the lid still puts the machine to sleep. No web page or extension can change that. It takes an OS setting, an external display or a native tool.
  • Low Power Mode shortens Auto-Lock. iPhone Low Power Mode forces a 30-second Auto-Lock. Separately, Firefox refuses a wake lock at 5% battery or less while not charging; the pill then reads Blocked — here's the fix and names the cause.
  • It does not touch your chat status. Teams, Slack and Zoom presence follows keyboard and mouse idle time, not the display. AwakeTab never simulates input to fake it.
  • Display sleep is not system sleep. A wake lock holds the screen, not the whole computer. For a machine awake with the screen off, use a native utility.
  • Other software keeps its own rules. A bank logout, a proctoring app, a monitor that sleeps on lost signal or a corporate lock-screen policy are outside a wake lock's reach.
